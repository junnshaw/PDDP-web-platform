# PDDP-web-platform
PDDP (http://www.deepaita.tech) is an easy-to-use and free drug discovery web platform that brings eight molecular and protein prediction or design workflows into a single browser interface. The platform addresses a practical problem in early-stage drug discovery: researchers often move among separate tools, install model-specific software, and reformat inputs before they can compare results. PDDP provides documented examples, model selection, server-side input validation, task-status tracking, and structured results without requiring registration. 

The deployed release provides eight core workflows: molecule-protein affinity prediction, drug-drug interaction prediction, protein phosphorylation-site prediction, molecular property prediction, molecule generation, protein-protein interaction prediction, structure-constrained molecular generation and optimization, and drug-microbe interaction prediction. Their configured models include MolTrans, DeepDTA, DeepConv-DTI, KGNN, DeepDrug, TransPhos, MG-BERT, MolFlow, DNN-XGB, JT-VAE, and Graph2MDA.
